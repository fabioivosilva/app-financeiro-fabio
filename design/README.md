# Design Reference

## App-financeiro-claude-design.zip

Design gerado pelo Claude em 2026-05-02.
Este é o **design oficial** a ser implementado no frontend v2.0.

### Conteúdo do zip

| Arquivo | O que é |
|---|---|
| `App Financeiro.html` | Preview completo no browser — abra este primeiro |
| `components/dashboard.jsx` | Componente do Dashboard |
| `components/importar.jsx` | Componente da tela de Importar |
| `components/provisoes.jsx` | Componente da tela de Provisões |
| `components/transacoes.jsx` | Componente da tela de Transações |
| `components/config.jsx` | Componente da tela de Configurações |
| `components/shell.jsx` | Layout base + Sidebar |
| `components/stubs.jsx` | Componentes auxiliares |
| `styles.css` | Estilos globais |
| `data.jsx` | Dados de exemplo |

### Como usar

1. Extrair o zip em qualquer pasta
2. Abrir `App Financeiro.html` no browser para ver o design completo
3. Usar os `.jsx` como referência visual e estrutural ao reescrever as páginas React

### Importante

Os `.jsx` do Claude são protótipos — **não copiar direto**.
Reescrever em TypeScript, conectar na API real, seguir os padrões do projeto.
Ver `obsidian-vault/10_CHECKPOINT_ATUAL.md` para o plano de implementação atual.
